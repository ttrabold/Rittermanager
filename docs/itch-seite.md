## Prototyp-Hinweis

Deutsch:

> 🚧 **Prototyp** – Fehler und Balance-Änderungen möglich, Spielstände können brechen. Sichere deinen Ritter regelmäßig im Spiel unter 💾 Spielstände → „Als Datei speichern“. Die aktuelle Versionsnummer steht dort ebenfalls.

English:

> 🚧 **Prototype** – bugs and balance changes are possible, saves may break. Back up your knight regularly in the game under 💾 Save slots → “Save as file”. The current version number is shown there too.
